# Local display font

`heritage-serif.css` defines the `Jiacheng Serif` family used by the application.
It vendors **Noto Serif SC Variable** version 5.3.1 from
`@fontsource-variable/noto-serif-sc`, published under the SIL Open Font License 1.1.

The font is split into Unicode-range WOFF2 files. Browsers request only the subsets
needed by the page, while the complete collection supports Chinese family names and
historical text without depending on a third-party font CDN.

The full license is retained in `NotoSerifSC-OFL.txt`.
