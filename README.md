# 家乘 JIACHENG · 可交互全栈原型

温润纸本、松柏绿与朱印红的家族在线族谱。技术栈为 Next.js App Router、React、PostgreSQL 与 Drizzle ORM；本环境遵循已有 PostgreSQL 基础设施，不冒充已经部署到 Cloudflare D1。

## 已实现

- 家谱总览：真实数据库统计、三代世系预览、逐册数字化进度、人物故事与修订。
- 世系图：分代窗口、分支展开折叠、拖拽、缩放、列表模式、定位本机身份。
- 族人名录：姓名、字、号、别名、拼音首字母、世代、地名搜索及筛选。
- 人物详情：生卒、小传、世系链、亲属、原文出处对照、增补子女。
- 本机「我是谁」，纯前端双向称谓与白话亲缘路径。不覆盖的关系不臆造称谓。
- 录入与编修：数据库持久化、同名提醒、谱外配偶排序、生母、父系循环校验、整支隐藏、软删除、恢复与人物修订快照回滚。
- 双历录入：原文优先、闰月和时辰、民国与常见清代纪年解析；1901 年前降级为年份，精度不伪装。使用 lunar-javascript；尚未完成设计书要求的完整金标验收，不作为历法权威。
- 老谱三栏工作台：原图缩放旋转、原文照录、关联人物、三态校对与逐页切换。
- 原谱影像批量上传（每批至多 20 张，每张 5MB；按文件名排序，演示中存为数据库内嵌影像）。
- 浏览器生成 PNG 分享长图，支持下载与生成后长按保存。
- A4 欧式行传体谱书：按世代与每页人数明确分页，目录页码对应排版页；浏览器打印成 PDF。
- 管理端 JSON / GEDCOM 下载，影像 ZIP 与 SHA-256 清单；JSON 差异预览、二次确认、事务化全量恢复。
- HttpOnly 服务端会话、管理/访客会话隔离、访问口令尝试限速与同源变更检查。

## 原型与隐私边界

所有内置人物、传记和影像均为虚构演示内容。生成的扫描图只用于展现界面，并不是真实史料。

默认未设置口令时，虚构家谱可直接浏览；点击管理入口可选择演示身份。**不要在无口令的演示实例录入真实隐私数据。** 部署时配置：

- `DATABASE_URL`：已有 PostgreSQL 连接。
- `ACCESS_CODE`：全站访客访问码，配置后未经验证不能读取谱数据。
- `ADMIN_PASSWORD`：独立管理口令，配置后关闭免密演示管理入口。

会话令牌以 SHA-256 摘要存入数据库，Cookie 为 HttpOnly / SameSite=Lax，生产环境 Secure。访客 30 天、管理 12 小时。口令通过固定长度摘要进行常数时间比较；部署环境变量由平台的秘密管理设施保护。

**尚未接入**阿里云盘、age 加密、Cron 自动备份、私有 OSS/CDN 与短时签名 URL。备份页如实显示「未配置」，不会伪造自动成功。内置样例图片在 public 下公开；真实上传图通过已鉴权数据库接口读取。正式使用前必须将影像迁到私有对象存储适配层，并完成存储签名、口令哈希及持久化分布式限速加固。当前不代表已经通过设计书 A1–A9 的生产验收。

## 运行

1. 安装依赖：`npm install`
2. 设置 PostgreSQL `DATABASE_URL`。
3. 同步表结构：`npx drizzle-kit push`。
4. 本地运行：`npm run dev`。

首个有效数据请求会以事务和 PostgreSQL advisory lock 初始化 128 位族人、13 代与 3 册 72 页示例。后续刷新不会覆盖修改。

## 备份恢复演练

1. 进入「管理与备份」，导出完整 JSON，另下载影像 ZIP；另存至独立设备。
2. 确认 JSON 含 `schemaVersion: 1`、人物数组、谱页数组与图片清单。ZIP 的 manifest 含每张影像 SHA-256。
3. 在单独的测试数据库启动第二个实例，勿直接清空唯一生产数据。
4. 选择 JSON，检查新增、移除、变更与谱页统计，输入「全量替换」。
5. 服务端会先校验 ID、关系循环、父母与谱页引用，再在事务中替换；失败整体回滚。
6. 对比前后人物数、世代、原文、隐藏状态，打开来源页；导出后再次比较资料。
7. 真实 OSS 适配器上线后，按 ZIP manifest 恢复对象与路径，再进行访客端对照验收。

演示上传图包含在 JSON 谱页中，内置图片依赖项目 public 资产；请保留图片包。真实云盘解密恢复与连续 14 天自动备份验收尚未执行。

## 校验

`npx next typegen` → `npm exec tsc -- --noEmit --pretty false` → `npm run build`。

核心规则回归：`npm exec --yes --package=tsx -- tsx scripts/core-check.ts`。

浏览器端到端实测：先准备 Playwright Chromium 与系统依赖，再对运行中的生产预览执行 `node scripts/smoke-test.mjs`（默认 localhost:3000，可用 TEST_BASE_URL 修改）。覆盖 GUI 录入和农历换算、世系缩放、拼音搜索、本机身份、亲缘称谓、父/母支系隐藏、循环拒绝、原文持久化、JSON/GEDCOM、媒体 ZIP、回收站状态与内嵌影像恢复、PNG 长图、PDF 页数和 375px 响应式。测试会在 finally 中恢复原始家谱与修订记录；自动备份服务的外部可靠性不在这些本地测试范围内。
